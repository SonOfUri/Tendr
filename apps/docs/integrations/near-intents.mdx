<Warning>
  Live NEAR Intents settlement is **not implemented yet**; it is coming in the checkout project.
</Warning>

Before enabling live mode:

1. Read https://docs.near-intents.org/
2. Record API versions, request/response examples, supported assets/networks, and limitations in an ADR
3. Implement provider methods without inventing fields
4. Keep credentials server-side (stored encrypted through the key vault)
5. Enable live settlement only after verifier tests pass
