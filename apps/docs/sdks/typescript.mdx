<Note>
  `@tendr/sdk` is not yet available as a public npm package. Use the [hosted HTTP API](/quickstart)
  for integrations today. The examples below describe the SDK interface; installation instructions
  will be added when the package is publicly available.
</Note>

```typescript
import { TendrClient, TendrApiError } from '@tendr/sdk';

const client = new TendrClient({
  baseUrl: 'https://api.usetendr.tech',
  apiKey: process.env.TENDR_SECRET_KEY,
  timeoutMs: 15_000,
});

const session = await client.checkoutSessions.create(
  {
    amount: '25.00',
    amount_currency: 'USD',
    external_ref: 'order-1042',
    success_url: 'https://shop.example/orders/1042',
    cancel_url: 'https://shop.example/cart',
  },
  { idempotencyKey: 'order-1042-checkout-1' },
);
```

The current session response type is `Record<string, unknown>`; validate or narrow fields before using them. The SDK adds authentication and optional idempotency headers, serializes requests and applies an AbortController timeout. It does not automatically retry requests or generate idempotency keys.

## Available methods

| Resource           | Methods                                                                                                                                 |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `checkoutSessions` | `create`                                                                                                                                |
| `paymentLinks`     | `create`, `list`, `retrieve`, `update`, `archive`                                                                                       |
| `themes`           | `presets`, `list`, `create`, `retrieve`, `update`, `delete`, `publish`, `setDefault`, `validate`, `preview`, `fromWebsite`, `fromStore` |
| `themeAssets`      | `upload`, `list`, `delete`                                                                                                              |

Session retrieval, refunds, invoices, wallet signing and AI do not have SDK convenience methods today. Use the documented HTTP surface and correct credential type.

## Payment links

```typescript
const link = await client.paymentLinks.create(
  { title: 'Design deposit', amount_type: 'fixed', amount: '250.00', currency: 'USD' },
  { idempotencyKey: 'design-deposit-1042' },
);

const page = await client.paymentLinks.list({ status: 'active', limit: 20 });
await client.paymentLinks.update(link.id, { status: 'inactive' });
await client.paymentLinks.archive(link.id);
```

## Errors

```typescript
try {
  await client.paymentLinks.retrieve('plink_example');
} catch (error) {
  if (error instanceof TendrApiError) {
    console.error(error.status, error.code, error.requestId);
  } else {
    // Transport errors and timeouts are not API error responses.
    throw error;
  }
}
```

## Verify a webhook

```typescript
import { verifyWebhookSignature } from '@tendr/sdk/webhook';

const valid = verifyWebhookSignature({
  payload: rawBody,
  signatureHeader,
  secret: endpointSigningSecret,
});
```

This export uses Node crypto. Verify raw request bytes before parsing and deduplicate event IDs. See [Webhook signatures](/security/webhook-signatures). Never bundle server keys or this Node-only module into a browser.
