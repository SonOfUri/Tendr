The hosted API base URL is `https://api.usetendr.tech`. Request and response bodies use JSON unless an upload endpoint explicitly requires multipart form data.

## Choose the right credential

| Surface                 | Credential                                              | Purpose                                                |
| ----------------------- | ------------------------------------------------------- | ------------------------------------------------------ |
| Merchant integration    | Secret API key                                          | Sessions, payment links, themes and refund requests    |
| Dashboard               | User session cookie, store/mode headers, CSRF on writes | Wallets, invoices, AI insights, webhook/key management |
| Hosted shopper checkout | Session `client_secret`                                 | One checkout's state, tokens, quotes and help          |
| Public invoice form     | Public submit plus emailed verification/receipt token   | Contractor workflow                                    |

A secret API key is not a dashboard session. For example, `GET /v1/payments`, webhook management and invoice-owner routes are dashboard-only. Use the merchant session read to reconcile your server-created payment.

## Conventions

- Send server keys as `Authorization: Bearer <key>`.
- Mode comes from the key. Test and live use the same base URL.
- Monetary values are strings. Session amounts use the stated currency; native payout amounts use token base units.
- Use an [idempotency key](/concepts/idempotency) for supported POST mutations.
- Follow each endpoint's pagination shape; there is no universal pagination contract.
- Preserve unknown response fields for compatibility. Do not send unknown request fields to strict endpoints.
