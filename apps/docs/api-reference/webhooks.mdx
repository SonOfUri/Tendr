title: Webhooks
---

<Note>
  Webhook delivery is coming in the checkout project. Events are already recorded in an append-only
  event log and dispatched by the worker through an outbox, which delivery will build on.
</Note>

Planned headers: `Tendr-Signature`, `Tendr-Timestamp`, `Tendr-Event-Id`, `Tendr-Event-Type`. See [Webhook signatures](/security/webhook-signatures).

Delivery will retry with exponential backoff.
