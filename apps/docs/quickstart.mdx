# Quickstart

```bash
cp .env.example .env
docker compose -f infra/docker/docker-compose.yml up -d   # Postgres + Redis
npm install
npm run build --workspace=@tendr/contracts
npm run db:migrate:dev --workspace=@tendr/api
npm run db:migrate:test --workspace=@tendr/api
npm run db:seed   # prints the Demo Merchant's API keys once
npm run dev
```

Check a seeded key against the API:

```bash
curl -sS http://localhost:4000/v1/ping \
  -H "Authorization: Bearer tdr_test_..."
```

```json
{
  "merchantId": "mer_...",
  "livemode": false,
  "principal": "secret_key",
  "scopes": ["sessions:read", "..."]
}
```

A `tdr_live_` key returns `"livemode": true`. See [API keys](/security/api-keys) for key formats and request signing.

<Note>Checkout endpoints (sessions, quotes, payments) are coming in the checkout project.</Note>
